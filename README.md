Sobre o Projeto
<br><br>
Estamos criando uma plataforma web, com versão mobile, para mercados de pequeno e médio porte. Nela, o mercado compra direto de fornecedores, controla estoque, financeiro e contabilidade e mantém licenças e alvarás em dia. A ideia é reduzir o custo de compra e organizar a gestão em um só lugar.
<br><br>
 
- 🛒 **Marketplace de compras:** compara fornecedores e preços e fecha o pedido.
- 📣 **Divulgação de mercadorias:** fornecedores divulgam lançamentos e promoções.
- 📦 **Gestão integrada:** estoque, financeiro e contábil (lançamentos prontos para o contador).
- 📋 **Regularização e licenças:** checklist de alvarás e alertas de vencimento.

## 🛠 Instalação
 
## FRONT-END
1. **Instalar Node.js** (se não tiver)
   - Baixe em: https://nodejs.org
   - Instale a versão LTS
2. **Instalar dependências**
```bash
npm install
```
 
## BACK-END
3. **Iniciar o servidor**
```bash
npm start
```
 
4. **Abrir no navegador**
   - http://localhost:3000
## API Endpoints (previstos)
 
- `GET /api/status` - Status da API
- `GET /api/produtos` - Consultar catálogo de produtos
- `POST /api/pedidos` - Registrar pedido de compra
- `GET /api/estoque` - Consultar estoque
<b>HTML:</b>
 
Não há instalação! Encontre o index.html na pasta executáveis e execute-o como uma página WEB (através de algum browser).
